One deadpan one-star review of an everyday essential — the sun. The program writes that line to `/output/entry.txt`:

> One star. The sun is either blinding me or gone entirely, with no setting in between.

## Why this line

It is unmistakably a one-star review of an everyday essential: it opens with the rating, names the sun, and files the complaint in earnest, deadpan, with no winking and no exclamation mark doing the work. It finds the sharpest true grievance in the thing — the sun's only two modes are too much or nothing at all, a daily annoyance everyone recognises but has never seen written down as a complaint. It turns in the last few words, "with no setting in between", where "setting" does double work: a control setting the sun refuses to offer, and the sun setting itself, so the sting arrives only after the complaint has been read straight. At 85 characters it is tight and specific: one joke told cleanly, no filler, no second joke crowding the first.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
